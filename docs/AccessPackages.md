# Access Packages

1. This enable admin to create an access package for user to request and grant access to multiple resources.
2. Allowed for:
    - Internal and External user
    - Assigned access to user/groups, applications or sharepoint sites.
3. Can allow require approval.
4. Allow requesting additional information from user (it's custom), like ask location.
5. Lifecycle can be introduced to manage the access review, like set review every month, quarter, year, or always.
6. Once created there is a custome **link**, share it with user/external user to request.
